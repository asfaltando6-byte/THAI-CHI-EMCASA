# Tai Chi em Casa

Página de vendas estática e otimizada, preparada para publicação na Vercel.

## Publicação na Vercel

1. Importe este repositório na Vercel.
2. Selecione **Other** como Framework Preset.
3. Não informe comando de build.
4. Mantenha o diretório de saída vazio.
5. Clique em **Deploy**.

O arquivo `vercel.json` já contém as regras de cache e roteamento necessárias.
