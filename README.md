# Tai Chi em Casa

Página de vendas estática e otimizada, pronta para publicação na Vercel.

## Publicar na Vercel

1. Importe o repositório `asfaltando6-byte/THAI-CHI-EMCASA`.
2. Selecione **Other** em Framework Preset.
3. Não informe comando de build.
4. Mantenha o diretório de saída vazio.
5. Clique em **Deploy**.

O projeto não exige instalação de dependências.
